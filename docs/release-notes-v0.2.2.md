근거를 처음 등록할 때 **무엇을 어떻게 써야 하는지** 몰라 막히는 문제를 해결했습니다.

## 새로 추가된 것

### ✳ 근거 예시로 양식 채우기

`근거` 탭에 **`예시로 양식 채우기 ▾`** 버튼이 생겼습니다.
누르면 도메인에 맞는 예시 목록이 뜨고, 고르면 양식이 통째로 채워집니다 —
근거 유형, 제목, 요약, 출처, 표본 수, **지지·반박 항목 체크까지**.

**examath** (초등 뺄셈)

| 예시 | 유형 | 지지 항목 |
|---|---|---|
| ① 학부모 인터뷰 | 사용자 인터뷰 (0.50) | D01~D05 — **이것만으로 HOLD가 풀립니다** |
| ② 종이 프로토타입 | 프로토타입 테스트 (0.70) | D05·D06·D10 / 반박 D08 |
| ③ 데스크 리서치 | 데스크 리서치 (0.35) | D08·D09 |
| ④ 교사 인터뷰 | 전문가 검토 | D03·D09 / 반박 D10 |

**VibeQuest** (바이브코딩 용어)

| 예시 | 유형 | 지지 항목 |
|---|---|---|
| ① 비개발자 인터뷰 | 사용자 인터뷰 (0.50) | D01~D05 — **HOLD 해제** |
| ② 3분 미션 클릭더미 | 프로토타입 테스트 (0.70) | D05·D06·D10 / 반박 D07 |
| ③ 데스크 리서치 | 데스크 리서치 (0.35) | D08·D09 |
| ④ 오픈채팅 질문 로그 | 행동 데이터 (1.00) | D02·D09 |

도메인을 지정하지 않은 프로젝트에도 일반 예시 3종이 들어갑니다.
`양식 비우기` 버튼도 함께 추가했습니다.

### ⚠ 예시는 근거가 아닙니다

예시를 채우면 붉은 경고가 함께 뜹니다.

> 이건 근거가 아니라 '이렇게 쓰세요'라는 예시입니다.
> 실제로 관찰하거나 들은 내용으로 바꾼 뒤 등록하세요.
> 예시 그대로 등록하면 자기 진단을 스스로 속이는 셈이 되어 판단이 무의미해집니다.

**AI는 근거를 생성하지 않는다**는 원칙은 그대로입니다.
이 기능이 채우는 것은 *양식의 형태*이지 *근거의 내용*이 아닙니다.

예시 요약문에는 이런 안내가 들어 있습니다.

```
※ 해석이 아니라 관찰된 사실로 적으세요.
   '부모들이 힘들어한다'(X) / '5명 중 4명이 ~라고 진술했다'(O)
```

②·④ 예시에는 **반박 항목이 미리 체크**되어 있습니다.
불리한 결과도 넣어야 진단이 의미 있다는 것을 예시로 보여주기 위해서입니다.
유리한 근거만 등록하면 신뢰도만 올라가고 판단은 틀어집니다.

## 참고: HOLD를 푸는 데 필요한 근거량

| 등록한 근거 | 전체 신뢰도 | 결과 |
|---|---:|---|
| 없음 | 0.20 | HOLD |
| 창업자 가정만 (몇 건이든) | 0.20 | **HOLD — 절대 안 풀림** |
| 인터뷰 1건, 3개 항목 지지 | 0.31 | HOLD |
| **인터뷰 1건, 5개 항목 지지** | **0.35** | **★ 풀림** |
| 인터뷰 + 프로토타입 테스트 | 0.47 | ★ 풀림 |

창업자 가정은 신뢰도 상한이 0.20이라 아무리 많이 등록해도 HOLD를 풀 수 없습니다.
실제로 누군가에게 물어본 근거가 있어야 합니다.

## 검증

- 테스트 120개 통과 (예시 기능 회귀 테스트 5개 추가)
  - 예시가 양식만 채우고 **등록되지는 않는가**
  - 도메인마다 다른 예시가 나오는가
  - 채운 예시가 실제로 등록 가능한 상태인가 (필수 항목 충족)
  - **"① 예시로 HOLD가 풀린다"는 안내가 사실인가** — 세 도메인 모두에서 계산 검증
  - 양식 비우기가 체크박스까지 초기화하는가
- 빌드된 실행파일에서 `--selftest` 통과

> 안내 문구와 실제 계산이 어긋나면 테스트가 깨지도록 했습니다.
> 문서가 거짓말을 하지 않게 하는 것이 이 프로젝트의 규칙입니다.
