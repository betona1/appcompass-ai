## 고친 것

### 🐞 A화면에서 아이디어를 고쳐도 반영되지 않던 문제 (중요)

**증상**
`A. 아이디어 입력`에서 타깃이나 문제 상황을 고쳐 새 버전으로 저장해도,
`B. 구조화 검토` 화면에는 **이전 버전 내용이 그대로** 표시되었습니다.
분석을 다시 실행해도 **점수와 판단이 똑같이** 나와서, 수정 자체가 저장되지 않는 것처럼 보였습니다.

**원인**
원문(raw)은 정상적으로 저장되고 있었지만, 실제 분석에 쓰이는 **구조화 결과**를 만들 때
이전 버전이 있으면 사용자의 새 입력을 통째로 무시하고 이전 값을 그대로 물려받았습니다.

**수정**
이번에 **원문이 바뀐 칸만** 구조화 값을 갱신하고, 안 고친 칸은 그대로 둡니다.

- A화면에서 고친 내용 → 구조화 결과와 분석에 **반영됩니다**
- B화면에서 공들여 다듬은 값(구매자, 첫 성공 경험 등) → **그대로 유지됩니다**
- 저장 후 상태 표시줄에 어떤 항목이 반영됐는지 알려줍니다

실제 확인 (타깃을 "모든 사람" → 상황 기반으로 좁힌 경우):

| | v0.1.0 (버그) | v0.1.1 (수정) |
|---|---|---|
| 타깃 명확성 | 1/5 그대로 | 1/5 → **4/5** |
| 총점 | 17.0 그대로 | 17.0 → **33.0** |

> **v0.1.0에서 만든 데이터는 그대로 쓰실 수 있습니다.**
> 다만 v0.1.0에서 A화면 수정이 반영되지 않은 버전이 있다면,
> `B. 구조화 검토`에서 내용을 확인하고 필요하면 새 버전을 만들어 다시 분석하세요.

## 설치

**Assets**에서 `AppCompass-AI-0.1.1-win64.zip` 을 받아 압축 해제 후 `AppCompass.exe` 실행.
Windows 10 이상 64비트, Python 불필요.

기존 사용자는 폴더만 새 것으로 교체하시면 됩니다.
데이터는 `%APPDATA%\AppCompass\appcompass.sqlite3` 에 따로 있으므로 사라지지 않습니다.

설치 확인:
```
AppCompass.exe --selftest
```
