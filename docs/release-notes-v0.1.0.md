앱 아이디어를 구조화하고 진단해 **유지·수정·피벗**을 판단하는 데스크톱 프로그램의 첫 공개 버전입니다.

> **AI가 정답을 결정하지 않습니다.**
> 이 도구는 문제를 구조화하고, 부족한 근거를 찾고, 검증할 실험을 제안합니다.
> 최종 결정은 사람이 승인합니다.

## 설치

### Windows 실행파일 (Python 불필요)

1. 아래 **Assets**에서 `AppCompass-AI-0.1.0-win64.zip` 다운로드
2. 압축 해제
3. `AppCompass.exe` 실행

Windows 10 이상 64비트. 압축 안에 `사용설명서.md`가 함께 들어 있습니다.

> **SmartScreen 경고가 뜨는 경우**
> 코드 서명이 되어 있지 않아 "Windows의 PC 보호" 창이 나올 수 있습니다.
> `추가 정보` → `실행` 을 누르면 됩니다. 걱정되시면 아래 소스 실행 방법을 쓰세요.

### 소스에서 실행

```bash
git clone https://github.com/betona1/appcompass-ai.git
cd appcompass-ai
pip install -r requirements.txt
python run_app.py
```

Python 3.11 이상.

### 설치 확인

```bash
AppCompass.exe --selftest
```

분석 파이프라인을 한 번 돌려 스키마 로딩·채점·판정·보고서 생성을 점검하고
`selftest.txt` 에 결과를 남깁니다.

## 무엇을 할 수 있나요

**아이디어 입력 → 구조화 검토 → 자동 진단 → 타깃 후보 → MVP → 피벗 보고서** 까지
전 과정이 동작합니다.

- **넓은 타깃을 잡아냅니다.** "모든 사람", "누구나", "수학을 배우는 아이 전체" 같은 표현을
  감지하고, 상황 + 현재 행동 + 중단 원인으로 다시 쓰도록 안내합니다.
- **사용자·구매자·영향자를 분리시킵니다.** 어린이·교육 맥락에서 구매자가 없으면 치명 경고를 냅니다.
- **10개 항목을 채점합니다.** 각 점수에 왜 그 점수인지가 문장으로 남습니다.
- **근거 없는 판단을 막습니다.** 근거를 등록하지 않으면 신뢰도가 0.20을 넘지 못하고
  판단은 `HOLD`가 됩니다. 대신 "근거가 충분했다면 무엇이었을지"를 함께 보여줍니다.
- **버전을 추적합니다.** 승인한 버전은 수정할 수 없고, 새 버전과 비교해
  무엇이 왜 바뀌었고 점수·판단이 어떻게 달라졌는지 볼 수 있습니다.
- **Markdown / HTML 보고서**를 내보냅니다.

## 설계 원칙

- **판정은 전부 결정론적 규칙 엔진**입니다. LLM을 사용하지 않습니다.
  같은 입력 + 같은 정책 버전이면 항상 같은 결과가 나옵니다.
- **AI는 근거를 만들지 않습니다.** 사람이 등록한 근거만 신뢰도에 반영됩니다.
- 모든 분석 결과는 저장 전 **JSON Schema 검증**을 통과해야 합니다.
  실패하면 `FAILED_SCHEMA`가 되고 그 결과로는 점수도 판정도 만들지 않습니다.
- 모든 결과와 보고서에 **엔진·정책·스키마 버전**이 기록됩니다.
- 생성·수정·삭제·분석·정책 변경은 **감사 로그**에 남습니다 (도구 → 감사 로그 보기).
- **인터넷 연결이 필요 없습니다.** 모든 계산이 로컬에서 이루어지고 외부로 데이터를 보내지 않습니다.

### 운영자가 바꿀 수 있는 것

정책 화면에서 10개 항목의 가중치와 모든 판정 임계치를 수정할 수 있습니다.
가중치 합계가 100이 아니면 저장이 거부됩니다.
정책을 바꿔도 기존 분석 결과는 그대로이며, 다시 실행해야 적용됩니다.

## 기술

```
ui (PySide6) → services (AppService) → storage (SQLAlchemy) → core (순수 파이썬)
```

`core`는 Qt·DB·네트워크에 의존하지 않습니다. 웹으로 옮길 때 `ui`만 교체하면 됩니다.

- Python 3.11+ / PySide6 6.9 / SQLAlchemy 2.0 / SQLite
- 테스트 88개 — 고정 시나리오 회귀, 재현성, 스키마 계약, 권한, UI 스모크
