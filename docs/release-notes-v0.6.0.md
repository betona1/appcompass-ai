지금까지 진단은 **기획**을 봤습니다. 이제 **콘텐츠 자체**도 봅니다.

| | 기획 진단 | 도메인 진단 (신규) |
|---|---|---|
| 대상 | 타깃·문제 정의 | 실제 문항 / 아이의 오답 |
| 예 | "타깃이 넓다" | "이 문항은 정의 암기형이다" |

기획서에 "실제 상황형 문제"라고 써 두어도 실제 문항이 `API란 무엇인가?`면 아무 소용이 없습니다.
그 간극을 메우는 것이 이번 버전입니다.

## 🧮 examath — 오류 유형 진단 (CLAUDE.md §5.5)

**뺄셈은 수학적으로 검증 가능합니다.** 아이가 쓴 답을 보면 어떤 절차를 밟았는지
역추적할 수 있습니다. 그래서 이 분류는 추측이 아니라 계산입니다.

| 입력 | 판정 | 근거 |
|---|---|---|
| `43 - 7 = 44` | 받아내림의 의미를 이해하지 못함 | 각 자리에서 큰 수−작은 수를 뺌 (7−3=4) |
| `43 - 7 = 40` | 받아내림 개념 부재 | 일의 자리를 계산 못 하고 0으로 둠 |
| `43 - 7 = 46` | 십의 자리와 일의 자리 혼동 | 10은 빌렸으나 십의 자리를 1 줄이지 않음 |
| `52 - 8 = 45` | 뒤로 세기가 어려움 | 정답과 1 차이 (하나 더/덜 셈) |
| 무응답 | 틀릴까 봐 시도하지 않음 | 계산 능력보다 먼저 해결할 문제 |

관찰된 행동(손가락 사용, 구체물로는 성공 등)을 함께 넣으면 후보가 좁혀집니다.

**판정 우선순위**: 관찰된 행동 → 절차 역추적 → 일반적인 수 감각.
`43-7=44`는 "답이 43보다 크다"도 사실이지만, **자리별 계산 오류**가 훨씬 구체적이고
개입 방법도 분명하므로 그쪽을 주 판정으로 삼습니다.

각 판정에 **무엇을 가르쳐야 하는지**가 함께 나옵니다.

> "십의 자리에서 10을 가져와 일의 자리에 합치는 과정을 구체물로 보여줍니다."

## 📝 VibeQuest — 문항 품질 점검 (CLAUDE.md §4.6~4.7)

이 도메인의 가장 큰 위험은 **일반 용어 퀴즈 앱으로 보이는 것**이고,
그건 문항 하나하나에서 결정됩니다.

문항을 넣으면 CLAUDE.md §4.6의 권장 유형 중 어디에 해당하는지 분류합니다.

```
정의와 실제 상황 연결 / 올바른 도구 선택 / 잘못된 AI 답변 찾기 /
코드·화면·오류와 용어 연결 / 유사 개념 차이 구분 / 작업 순서 배열 /
시나리오형 4지선다 / 짧은 주관식 (키워드 채점)
```

권장 유형에 들지 않으면 경고합니다.

| 문항 | 판정 |
|---|---|
| `API란 무엇인가?` | **단순 정의 암기형 (치명)** — 외우면 맞지만 실제 작업에 전이되지 않습니다 |
| `배포하려는데 'API key not found' 오류가 났습니다. 먼저 확인할 것은?` | 정의와 실제 상황 연결 ✔ |

함께 점검하는 것:

- 실제 작업 상황이나 코드·오류 메시지가 있는가
- 어떤 프로젝트 단계인지 드러나는가
- 대상 난이도가 지정됐는가 (초보자와 현업의 난이도 충돌 방지)
- 보기가 3개 이상인가
- **정답 해설이 있는가** (없으면 치명 — 틀렸을 때 배우는 게 없습니다)
- **출처가 있는가** (없으면 AI가 만든 부정확한 문항을 걸러낼 방법이 없습니다)

## 분류를 확정처럼 보이게 하지 않았습니다

모든 결과에 한계를 함께 표시합니다.

> 이 분류는 입력한 내용만 보고 규칙으로 판정한 것입니다.
> 실제 원인은 아이(사용자)를 직접 관찰해야 확인됩니다. 분류가 맞는지 반드시 사람이 확인하세요.

확정처럼 보이면 사용자가 관찰을 멈춥니다.

**패턴이 안 잡히면 지어내지 않습니다.** `분류 불가`로 두고
"아이에게 어떻게 풀었는지 직접 물어보라"고 안내합니다.

문항 품질 점검도 **사실관계(정답이 실제로 맞는지)는 검사하지 않는다**고 명시합니다.

## 새 도메인을 추가해도 화면은 바뀌지 않습니다

양식(`content_spec`)과 판정(`diagnose_content`)을 도메인 모듈이 갖습니다.
화면은 그 양식을 그리고 결과를 보여줄 뿐입니다.

도메인에 진단할 고유 콘텐츠가 없으면 `None`을 반환하고 탭이 비활성화됩니다.
억지로 만들면 의미 없는 양식이 되기 때문입니다.

## 작업 중 잡은 오분류 2건

- `43-7=44`가 "수의 크기 비교"로 분류됐습니다 → 절차 역추적을 우선하도록 순서 변경
